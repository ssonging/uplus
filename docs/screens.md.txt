# screens.md — 화면 설계서

플로우 순서: 요금제 목록 → 요금제 상세 → 구독 신청 → 신청 완료.

- 플로우의 '요금제 추천 화면'은 예시의 '요금제 목록'에 대응한다.
- 정보 입력·약관 동의·입력 검증·오류 표시는 구독 신청 화면 내부 단계다.
- 실제 라우트는 자료에 없어 미정으로 표기한다.
- '신규:'는 별도 라이브러리 컴포넌트로 등록되지 않은 UI를 뜻한다.

## 요금제 목록

### 목적
- 요금제를 확인하고 선택한 요금제의 상세 화면으로 이동한다.

### 라우트
- 미정: 실제 경로 미제공. 화면에 대응하는 라우트 1개 필요.

### 구성 요소
- Header: Type=root, Title='요금제 목록'. 내부 Logo 표시.
- FilterChip:
  - '전체': State=selected.
  - '베이직'·'스탠다드'·'프리미엄': State=default.
  - 필터 UI는 예시에 있으나 변경 시 동작은 미정.
- Card/Plan: State=default, Badge=false, Promo=false, Sale=false.
  - 베이직: 월 5,900원 / 월 10회 이용 · 기본 기능 제공.
  - 스탠다드: 월 9,900원 / 월 30회 이용 · 기본 기능 + 이용 기록.
  - 프리미엄: 월 14,900원 / 무제한 이용 · 기본 기능 + 이용 기록.
- Button: 카드 내부, Type=Secondary, Size=sm,
  State=Default, Label='요금제 보기'.
- 신규: 목록 안내
  - '나에게 맞는 요금제를 선택하세요'.
  - '요금제별 혜택을 확인한 후 구독할 수 있어요.'.
  - 예시에 있는 일반 텍스트 영역.
- 신규: 요금 안내 문구
  - '모든 요금은 부가세 포함 금액입니다.'.
  - 예시에 있는 일반 텍스트.

### 상태
- 기본: 요금제 3개와 가격·혜택 표시. '전체' 필터 선택.
- 로딩: 자료에 정의 없음.
- 빈: 자료에 정의 없음.
- 에러: 자료에 정의 없음.

### 이동
- 들어오는 곳: 플로우 시작 / 요금제 상세에서 '뒤로 가기'.
- 나가는 곳: 요금제 카드 선택 → 선택한 요금제 상세.
  예시의 '요금제 보기'가 상세 진입 버튼이다.

## 요금제 상세

### 목적
- 선택한 요금제의 가격·혜택·구독 안내를 확인하고
  신청 여부를 결정한다.

### 라우트
- 미정: 실제 경로 미제공. 화면에 대응하는 라우트 1개 필요.

### 구성 요소
- Header: Type=default, Title='요금제 상세'.
  내부 icon/arrowLeft 표시.
- 신규: 선택 요금제
  - 예시의 일반 프레임이며 Card/Plan 인스턴스가 아니다.
  - 스탠다드 / 월 9,900원.
  - '부가세 포함 · 매월 정기 구독'.
- List/Row: Type=check, Value는 빈 문자열.
  - Label='월 30회 이용'.
  - Label='기본 기능 제공'.
  - Label='이용 기록 확인'.
- List/Row: Type=default.
  - 이용 기간 / 신청일부터 1개월.
  - 갱신 주기 / 매월 자동 갱신.
- 신규: 구독 안내 문구
  - '이용 횟수는 매월 새로 제공되며,
    남은 횟수는 다음 달로 이월되지 않습니다.'.
- BottomCTA: Layout=double.
  - 내부 Button: Type=Secondary, Size=xl,
    State=Default, Label='뒤로'.
  - 내부 Button: Type=Primary, Size=xl,
    State=Default, Label='구독 신청'.
  - '구독 신청'은 플로우의 '신청하기 클릭'에 대응한다.

### 상태
- 기본: 선택한 요금제 상세 표시. 제공된 예시는 스탠다드 기준.
- 로딩: 자료에 정의 없음.
- 빈: 자료에 정의 없음.
- 에러: 자료에 정의 없음.

### 이동
- 들어오는 곳: 요금제 목록에서 요금제 선택.
- 나가는 곳:
  - '뒤로' → 요금제 목록.
  - '구독 신청' → 구독 신청.

## 구독 신청

### 목적
- 신청 내용을 확인하고 신청자 정보를 입력한다.
- 약관 동의와 입력 완료 여부 확인을 거쳐 신청한다.
- 플로우의 '신청 폼 입력 화면'에 대응한다.
- 정보 입력·약관 동의·검증·오류 표시는 별도 화면으로 분리하지 않는다.

### 라우트
- 미정: 실제 경로 미제공. 화면에 대응하는 라우트 1개 필요.

### 구성 요소
- Header: Type=default, Title='구독 신청'.
  내부 icon/arrowLeft 표시.
- List/Row: Type=default. 예시의 신청 내용:
  - 요금제 / 스탠다드.
  - 월 요금 / 9,900원 (부가세 포함).
  - 제공 혜택 / 월 30회 이용.
  - 이용 시작 / 신청 완료 후 바로 이용.
  - 제공 혜택 보조 문구: '기본 기능 + 이용 기록'.
- Input: 예시에 배치된 이름·이메일 입력.
  - State=filled, errorMessage=false.
  - 표시값: 김민수 / minsu@example.com.
  - 표시값은 예시 데이터다.
- Input: 플로우에 있는 연락처·주소 입력에 기존 컴포넌트 재사용.
  - 예시 화면에는 없으므로 추가 배치 필요.
  - 입력값·형식은 미정.
- Checkbox: 플로우의 '약관 동의 체크'에 기존 컴포넌트 재사용.
  - 등록된 상태값: State=default, active.
  - 예시 화면에는 없으므로 추가 배치 필요.
  - 약관 문구·필수 여부는 미정.
- 신규: 신청 안내 문구
  - '신청 내용을 확인해 주세요.
    구독은 신청일부터 매월 자동 갱신됩니다.'.
- BottomCTA: Layout=double.
  - 내부 Button: Type=Secondary, Size=xl,
    State=Default, Label='취소'.
  - 내부 Button: Type=Primary, Size=xl,
    State=Default, Label='신청'.
- 자료 간 차이:
  - 플로우: 이름·연락처·주소 입력 → 약관 동의 체크.
  - 예시 화면: 이름·이메일 입력만 표시.
  - 이메일의 필수 여부는 정하지 않는다.
  - 연락처·주소·약관 동의가 이미 배치된 것으로 간주하지 않는다.

### 상태
- 기본:
  - 신청 내용과 신청자 정보 영역 표시.
  - 정보 입력 → 약관 동의 체크 → 입력 완료 여부 확인 순서.
  - 예시의 이름·이메일은 Input State=filled.
- 로딩: 자료에 정의 없음.
- 빈:
  - 필수 항목 미입력은 플로우의 에러 분기로 처리.
  - 별도 빈 화면은 정의 없음.
- 에러:
  - 필수 항목 미입력 → 오류 메시지 표시 → 정보 입력 단계로 복귀.
  - Input의 State=caution, errorMessage=true 사용 가능.
  - 실제 필수 항목 목록·오류 문구·약관 오류 표현은 미정.
  - 별도 오류 화면은 추가하지 않는다.

### 이동
- 들어오는 곳: 요금제 상세에서 '구독 신청'.
- 나가는 곳:
  - 모든 항목 입력 완료 → 신청 완료.
  - 필수 항목 미입력 → 같은 화면의 정보 입력 단계.
  - '취소'와 헤더 뒤로 버튼의 목적지: 자료에 없어 미정.

## 신청 완료

### 목적
- 구독 신청 완료와 신청 내역을 확인한다.

### 라우트
- 미정: 실제 경로 미제공. 화면에 대응하는 라우트 1개 필요.

### 구성 요소
- Header: Type=default, Title='신청 완료'.
  내부 icon/arrowLeft 표시.
- icon/doneMark: 완료 표시. 내부 icon/check 포함.
- 신규: 구독 신청 완료 안내
  - '구독 신청이 완료됐어요'.
  - '신청한 구독을 바로 이용할 수 있어요.'.
- List/Row: Type=default. 예시의 신청 내역:
  - 신청 번호 / 2026-1013-0024.
  - 요금제 / 스탠다드.
  - 월 요금 / 9,900원.
  - 신청 일시 / 10월 13일 14:02.
  - 신청자 / 김민수.
  - 위 값은 화면의 예시 데이터이며 실제 신청 결과로 확정하지 않는다.
- BottomCTA: Layout=single.
  - 내부 Button: Type=Primary, Size=xl,
    State=Default, Label='완료'.

### 상태
- 기본: 완료 표시·완료 문구·신청 내역 표시.
- 로딩: 자료에 정의 없음.
- 빈: 자료에 정의 없음.
- 에러: 자료에 정의 없음.

### 이동
- 들어오는 곳: 구독 신청에서 모든 항목 입력 완료.
- 나가는 곳:
  - 플로우는 신청 완료 화면 다음 '종료'로 연결된다.
  - 예시의 '완료' 버튼 클릭 후 경로는 미정.
  - 헤더 뒤로 버튼의 목적지도 미정.
  - 별도 종료 화면은 추가하지 않는다.
