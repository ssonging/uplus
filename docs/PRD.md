## 1. 배경

데이터가 다 떨어진 고객은 추가 데이터를 사는 것보다 요금제를 바꾸는 게 더 이득이라고 판단하면 요금제 변경을 알아본다. 이때 데이터를 빨리 다 썼거나, 데이터가 다시 들어오는 날까지 많이 남은 경우가 많다.

회사는 구독 서비스 묶음 혜택을 보여 줘서 고객이 더 비싼 요금제를 고르도록 유도하고 싶다.

## 2. 문제 정의

| ID | 문제 |
|---|---|
| P1 | 요금제가 너무 많아서 고객이 어떤 요금제로 바꿔야 할지 모른다. |
| P2 | 고객은 자기가 인앱에서 따로 내는 구독료를 잘 몰라서, 묶음 요금제가 전체 금액 기준으로 더 싼지 판단하지 못한다. |
| P3 | 공시지원금 반환이나 구독 중복 결제처럼, 바꾼 뒤에 생기는 불이익을 고객이 미리 알기 어렵다. |

## 3. 목표

| 구분 | 목표 |
|---|---|
| 고객 | 필요한 데이터 양을 채우는 요금제 중, 지금 내는 금액과 비교해 이득인 요금제로 바꾼다. |
| 회사 | 구독 서비스 묶음 혜택을 보여 줘서 더 비싼 요금제 선택을 유도한다. |
| 두 목표가 만나는 지점 | "지금 요금제 + 구독료"와 새 요금제의 전체 금액을 비교해 묶음 요금제가 이득임을 보여 준다. |

## 5. 유저 스토리

| ID | 유저 스토리 |
|---|---|
| US1 | 요금제 변경 고객은 필요한 데이터 양을 정하기 위해 자기 데이터 사용량을 확인한다. |
| US2 | 요금제 변경 고객은 너무 많은 요금제 중에서 후보를 줄이기 위해 필요한 데이터 양으로 요금제를 거른다. |
| US3 | 요금제 변경 고객은 가장 저렴한 요금제를 찾기 위해 후보 요금제의 월 요금을 비교한다. |
| US4 | 인앱 구독을 따로 내는 고객은 묶음 요금제가 더 이득인지 판단하기 위해 자기가 쓰는 구독 서비스를 고르고 "지금 요금제 + 구독료"와 새 요금제를 비교한다. |
| US5 | 요금제 변경 고객은 바꾼 뒤 불이익을 피하기 위해 지원금 반환과 구독 중복 결제 안내를 확인한다. |
| US6 | 요금제 변경 고객은 요금제를 바꾸기 위해 요금제 변경을 신청하고 결과를 확인한다. |

## 6. 요구사항

모두 **필수**다.

### F1. 데이터 양으로 거르기 (P1 · US1~US3)

| ID | 요구사항 | 근거 |
|---|---|---|
| F1-1 | 고객의 데이터 사용량(이번 달 쓴 양, 남은 양, 다시 들어오는 날, 지난 달 쓴 양)을 보여 준다. | DOMAIN 6장 |
| F1-2 | 고객이 필요한 데이터 양으로 요금제를 거를 수 있다. 데이터 사용량을 참고값으로 쓴다. | |
| F1-3 | 거른 요금제의 월 요금, 데이터 양, 묶인 구독 서비스를 보여 주고, 월 요금을 비교할 수 있다. | |
| F1-4 | 고객의 지금 요금제를 구분해 보여 준다. | BR10 |

### F2. 구독료 비교 (P2 · US4)

| ID | 요구사항 | 근거 |
|---|---|---|
| F2-1 | 고객이 쓰는 구독 서비스를 유튜브, 넷플릭스, 디즈니플러스, 티빙 중에서 직접 고를 수 있다. | BR12 |
| F2-2 | 고른 구독 서비스의 대표 구독료로 "지금 요금제 + 구독료"를 계산한다. | BR9 |
| F2-3 | "지금 요금제 + 구독료"와 새 요금제의 전체 금액 차이를 보여 준다. | |
| F2-4 | 요금 차이와 혜택은 투명하게 보여 준다. | 원칙 |

### F3. 예외 안내 (P3 · US5)

| ID | 요구사항 | 근거 |
|---|---|---|
| F3-1 | 지금 쓰는 요금제를 고르면 지금 쓰는 요금제라고 알리고 신청을 막는다. | BR10 |
| F3-2 | 공시지원금 고객이 약정 기간 안에 기준 금액 미만 요금제를 고르면, 지원금 반환 금액을 보여 주고 동의를 받는다. | BR3~BR5, BR7 |
| F3-3 | 지원금 반환 금액 = 지원금 × (남은 약정 기간 ÷ 전체 약정 기간) | BR4 |
| F3-4 | 선택약정 고객에게는 지원금 반환 안내를 하지 않는다. | BR6 |
| F3-5 | 고객이 고른 구독 서비스가 새 요금제에 묶여 있으면, 기존 인앱 구독을 직접 해지해야 한다고 안내한다. | BR8, BR11 |

### F4. 요금제 변경 신청·완료 (US6)

| ID | 요구사항 | 근거 |
|---|---|---|
| F4-1 | 신청 전에 변경 내용(지금 요금제, 새 요금제, 금액 차이)을 확인한다. | |
| F4-2 | 약관에 동의한다. | |
| F4-3 | 필요한 정보를 입력한다. 입력 항목은 미정이며 예시로 대신한다. | 열린 질문 3 |
| F4-4 | 지원금 반환이 생기면 반환 동의를 받는다. | F3-2 |
| F4-5 | 신청하면 새 요금제가 즉시 적용된다. 그달 요금과 데이터는 날짜만큼 나눠 계산된다는 것을 알린다. | BR1, BR2 |
| F4-6 | 신청이 끝나면 완료와 신청 내역을 보여 준다. | |
