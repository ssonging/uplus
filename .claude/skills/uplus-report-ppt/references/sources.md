# 분석한 기준 문서

모든 파일은 사내 DRM(Microsoft 정보보호)으로 암호화되어 있어, `scripts/read_ppt.ps1`(PowerPoint 읽기 전용)으로만 열 수 있다.

## 메모
- 파일명에 `●` 같은 특수문자가 있으면 PowerPoint COM이 열지 못한다. `read_ppt.ps1`은 영문 이름의 임시 사본을 만들어 연 뒤 사본을 지운다.
