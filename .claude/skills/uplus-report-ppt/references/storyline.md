# 장표 유형과 목차 후보

목차를 제안할 때 아래 유형에서 고른다. 기준 문서에서 실제로 쓰인 순서는 대체로 `배경 → 상품안 → 가격 근거 → 예상 매출 → 전략 → 일정 → 별첨`이다.
각 유형의 "헤드메시지 예시"는 문장 형태를 보여주는 틀일 뿐이다. 수치는 사용자 자료로 채운다.

## 본문 장표

### 1. 상품 구성 (첫 장 겸 요약)
- 헤드메시지: `{문제}를 해결하고자 {상품}을 출시하여, {목표}하겠습니다.`
- 서브 메시지: 현재 문제를 수치로 제시 (예: 기존 상품의 건당 마진)
- 근거: 제휴 서비스별 `1. 서비스명` 설명 + 3x2 가격표(상품/정가/정산가, `VAT 없음`), 현재 카테고리 매출·순이익 표(제휴사명/RS/판매가/판매건/매출/순이익)

### 2. 출시 배경 (시장 및 고객 / 경쟁사 / 자사)
- 왼쪽 라벨 3개 + 오른쪽 개조식 본문. 자사 칸은 `(열위)`, `(기회)` + `→`로 시사점을 쓴다.
- 오른쪽 위에 `[상품안]` 표(구분/상품/정가/구독료/정산/건당매출, 1안·2안)를 두고, 아래에 `[고객 가치]`(타겟/니즈·페인포인트/고객 가치)와 `[출시전략]`을 둔다.

### 3. 소비자가 선정기준
- 헤드메시지: `{번들}의 소비자가를 {가격}원으로 책정하여, {경쟁 상품}에 대응하고 {마진}을 확보하겠습니다.`
- 서브 메시지: `①` 고객 가치, `②` 마진 개선(예: `1,200원→7,100원, 5.9배`)
- 근거: 번들 산식 도식 `[A] + [B] = [A+B]` (판매가/정가/정산가/할인율/자사 RS)

### 4. 예상 매출 (시뮬레이션)
- 헤드메시지: `출시 {N}개월 차에 {목표}를 달성하고, 월 {금액} 규모의 이익을 확보하겠습니다.`
- 근거: 표(구분/예상 규모/예상 순이익/비고). 순이익 칸에 산식을 그대로 적는다. 오른쪽 위에 월별 전환 시뮬레이션 표.
- 가정(전환율, 신규 유입 수)은 모두 `[가정]`으로 표시하고 근거를 `*` 각주로 단다.

### 5. 프로모션 / 출시 전략
- 헤드메시지: `{모멘텀}과 연계하여 {소구점}을 선점하고, {혜택}으로 초기 가입자를 확보하겠습니다.`
- 근거: 대상 모수 → 예상 가입 수 추정 흐름, 재원(`* 삼성 마케팅 재원 활용`) 각주, 과거 유사 프로모션 실적 각주.

### 6. 세부 실행계획 및 진행현황
- 헤드메시지: `아래와 같이 주차별 계획을 수립하여 출시를 준비하겠습니다.`
- 근거: 간트 일정표(협상/운영 행) + 마일스톤, `진행현황(M/D 기준)` 목록, 담당 팀 표기.

### 7. 협상안 (필요 시)
- 헤드메시지: `기존 RS 조건으로는 {문제}가 어려워, {협상 목표}가 필요한 상황입니다.`
- 근거: `[현안]` 표와 `[협상안]` 표를 위아래로 비교하고, 오른쪽에 `[RS 현황]` 소형 표.

### 8. 연계형 출시 (요금제·미디어혜택 연계 시)
- 왼쪽 라벨(`상품`/`계약`/`유독 연계`/`자동 문자`) + 오른쪽 표(요금제 구간별 혜택 전/후, 서비스 비용 비교), 출시 일정 타임라인, 정산·계약 조건 표.

## 별첨 장표 (`별첨. {주제}`)
- 시장 현황: 주요 플랫폼 특징 비교표(구분/강점/정가/규모)
- 경쟁사 상품 포트폴리오: S사·K사 상품표(구분/상품명/등급/추가 혜택/정가/소비자가/프로모션가/할인율/비고)
- 경쟁력 평가: 가중치 기반 평가표 (고객/콘텐츠/제휴 관점)
- 상품 설명: 제휴사 서비스 화면 캡처 (사용자가 준 이미지만 사용)
- 가입자·이용행태: 차트 이미지 + 12pt 해설 + 녹색(`#00B050`) 출처 캡션
- 가격 제안·정산 기준: 혜택명/혜택내용/정가/고객 구독료/정산/건당매출 표

## 목차 제안 예시
| # | 유형 | 장표 제목 |
|---|---|---|
| 1 | 상품 구성 | {상품명} 상품 출시 보고_상품 구성 |
| 2 | 소비자가 선정기준 | {상품명} 상품 출시 보고_소비자가 선정기준 |
| 3 | 예상 매출 | {상품명} 상품 출시 보고_예상 매출 |
| 4 | 프로모션 | {상품명} 상품 출시 보고_프로모션 |
| 5 | 실행계획 | 세부 실행계획 및 진행현황 |
| 6 | 별첨 | 별첨. 경쟁사 상품 현황 |
