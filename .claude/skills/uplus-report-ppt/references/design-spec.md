# 디자인 규격 (스타일 A: 실무 출시보고형)

기준 문서 3개(교보sam+모아진, 티빙팩, 상품출시 Process 운영안)의 공통 서식을 PowerPoint에서 직접 측정한 값이다. 단위는 pt(1pt = 1/72인치)이고 좌표는 슬라이드 왼쪽 위 기준 `(left, top)`이다.
`[가정]`은 측정하지 못해 추정한 값이다.

## 슬라이드
- 크기 **960 x 540 pt (16:9)**, 배경 흰색, 레이아웃은 "빈 화면".
- 본문 영역: 좌 51 ~ 우 930, 상 86 ~ 하 525.

## 공통 헤더 (모든 장표)
| 요소 | 위치 / 크기 | 서식 |
|---|---|---|
| 제목 앞 점 | 원 (51, 40), 8x8 | 채움 `#FF3399`, 선 없음 |
| 제목 | 텍스트상자 (67, 33), 713x25 | LG스마트체 Regular **20pt**, 검정, 굵게 아님, 여백 0 |
| 구분선 | 직선 (51, 59) → (797, 59), 길이 746 | `#D9D9D9`, **1.5pt**, 실선 |
| 로고 | 그림 (804, 35), 113x29 | `assets/logo.png` |

제목 형식은 `{상품명} 상품 출시 보고_{주제}`이고, 별첨은 `별첨. {주제}`이다.

## 표
- 폰트 LG스마트체 Regular **10~12pt**, 가운데 정렬(숫자 열은 오른쪽 정렬도 가능).
- 테두리 `#808080` 0.5pt, 가로선 위주. 머리행·구분 열 채움은 `#F2F2F2`.
- 강조할 값(판매가, 자사 RS 등)은 **굵게 + 파랑 `#0000FF`**.
- 작은 가격표(3x2: 상품/정가/정산가)는 162x54 크기로 만들고, 여러 개를 가로로 나란히 둔다.
- 행이 15개를 넘으면 별첨으로 옮기거나 (1/2)(2/2)로 나눈다.

## 자주 쓰는 도식
- **번들 산식**: `[A 가격표] + [B 가격표] = [번들 가격표]`. 사이의 `+`, `=`는 LG스마트체 20pt 굵게, 각 표 아래 `#F2F2F2` 둥근 사각형 배경을 깐다.
- **좌측 구분 라벨 + 우측 내용**: 왼쪽에 68x(80~140) 사각형 라벨(`시장 및 고객`/`경쟁사`/`자사`, 11pt 굵게), 오른쪽에 개조식 본문(`(우위)`/`(열위)`/`(기회)` + `→` 근거).
- **간트 일정표**: 주차 열 표(1월 4주 … 3월 2주) 위에 `#F2F2F2` 둥근 막대(10pt 라벨)를 얹고, 위쪽에 진핑크 10pt로 마일스톤(`언팩(2/26)` 등)을 적는다. 아래에 `진행현황(M/D 기준)` 소제목과 `ㆍ날짜: 내용 / → 결과` 목록을 둔다.
- **타임라인**: 가로 화살표 위에 날짜(Arial Narrow 11pt 굵게), 아래에 업무와 담당 팀(최소 9pt), 마디마다 11x11 원.
- **단계 흐름**: `#D9D9D9` 오각형(Pentagon) 화살표를 가로로 이어 붙이고, 위에 `D-4M … Dday … D+1M`을 표기한다.
- **현안 vs 협상안**: 왼쪽에 80x107 라벨(`[현안]` / `[협상안]`, 11pt 굵게), 오른쪽에 같은 구조의 표를 위아래로 둔다.

## 폰트 정리
- 기본: **LG스마트체 Regular / SemiBold / Bold** (이 PC에 설치되어 있음).
- 표 제목·숫자 라벨: **Arial Narrow**.
- 최소 크기 9pt(각주·출처만). 본문 12pt 이상.
